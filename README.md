# Telegram-бот для оценки риска подделки товаров (Kaspi / Wildberries / Ozon)

Этот проект — шаблон Telegram-бота, который помогает **оценить вероятность того, что товар может быть подделкой**.

> ⚠️ Важно: бот делает **эвристическую оценку риска**, а не юридически подтверждает подделку.

## Что умеет бот

- Принимает карточку товара через команду `/check`.
- Считает риск по ряду факторов:
  - слишком низкая цена относительно рынка;
  - подозрительно низкий рейтинг;
  - мало отзывов;
  - новый продавец;
  - неофициальный продавец для брендов с высоким риском подделок;
  - в описании есть триггер-слова (`реплика`, `копия`, и т.п.).
- Возвращает:
  - числовой риск (0–100);
  - уровень риска (низкий / средний / высокий / очень высокий);
  - список причин.

## Быстрый старт

### 1) Установка зависимостей

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2) Настройка окружения

Скопируйте пример:

```bash
cp .env.example .env
```

В `.env` укажите токен бота:

```env
BOT_TOKEN=ваш_telegram_bot_token
```

### 3) Запуск

```bash
python bot.py
```

## Формат команды `/check`

Бот ожидает JSON после команды `/check`.

Пример:

```text
/check {
  "marketplace": "ozon",
  "title": "Apple AirPods Pro 2",
  "brand": "Apple",
  "price": 12990,
  "median_market_price": 24990,
  "rating": 4.3,
  "reviews_count": 17,
  "seller_name": "Best Deals 24",
  "seller_official": false,
  "seller_age_days": 8,
  "description": "Оригинал, супер цена, копия 1:1"
}
```

## Логика оценки

Алгоритм находится в `risk_engine.py`:

- базовый риск = 5;
- за каждый фактор начисляются штрафные баллы;
- итог ограничивается диапазоном 0..100.

Пороговые уровни:

- `0..24` — низкий;
- `25..49` — средний;
- `50..74` — высокий;
- `75..100` — очень высокий.
