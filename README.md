# Telegram-бот для оценки риска подделки товара

Бот принимает ссылку на товар с **Kaspi / Wildberries / Ozon** и возвращает эвристическую оценку вероятности подделки.

## Возможности
- Проверка карточки товара по URL.
- Определение платформы (Kaspi, Wildberries, Ozon).
- Поиск подозрительных маркеров в тексте (например: `реплика`, `копия`, `не оригинал`).
- Учет ценового отклонения, если указана официальная (референсная) цена.
- Рекомендации по дальнейшей ручной проверке.

## Быстрый старт

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Создайте `.env` на основе примера:
   ```bash
   cp .env.example .env
   ```

3. Укажите токен Telegram-бота в `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   REQUEST_TIMEOUT_SECONDS=10
   ```

4. Запустите бота:
   ```bash
   python bot.py
   ```

## Команды бота
- `/start` — приветствие.
- `/help` — инструкция по использованию.
- `/check <url> [референсная_цена]` — проверка товара.

Примеры:
- `/check https://kaspi.kz/shop/p/primer 220000`
- `/check https://www.ozon.ru/product/primer`

## Важно
- Оценка строится на эвристиках и не гарантирует 100% точность.
- Для финального решения всегда дополнительно проверяйте продавца, документы и отзывы.
